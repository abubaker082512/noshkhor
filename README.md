# NoshKhor (نوش خور) — Web Platform & Onboarding Portal

Official web presence and onboarding engine for **NoshKhor (نوش خور)** — Pakistan's 1st Dine-In Price Parity Delivery Platform.

## 🚀 Live Vercel Deployment
This repository is configured for automatic 1-click deployment on [Vercel](https://vercel.com):
- Framework Preset: **Other**
- Root Directory: `./` (or leave default)
- Build Command: `None`
- Output Directory: `./`

## 🌟 Key Features
- **Dine-In Price Parity Showcase**: Transparent comparison highlighting 0% markups.
- **Interactive Delivery Fee Estimator**: Real-time slider calculating `PKR 40 base + PKR 20/km`.
- **Restaurant / Kitchen Onboarding Form**: Self-service onboarding for restaurants, mother's home kitchens, and grocery marts with NTN and Raast ID capture.
- **Rider Fleet Onboarding Form**: Fast-track KYC for riders with CNIC, motorcycle registration, driving license, and instant Raast cashout setup.
- **App Download Center**: Direct access to all 4 standalone mobile APKs (Customer, Vendor, Rider, Admin).
